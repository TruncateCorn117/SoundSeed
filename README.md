# SoundSeed

**圈出几段声音，搜索整条录音。**

Local-first, teachable sound search. Give SoundSeed a few examples in a WAV recording, review the matches, and teach it which sounds to ignore. Audio processing stays in your browser.

SoundSeed 是一个可以直接用自己的录音试用的声音搜索工作台。你不用先给声音命名：圈出几次门铃、机器提示音或鸟叫，系统就会寻找相似的片段；点掉误报后，轻量分类器会重新排序候选结果。

第一版专注于一个完整的循环：**选样例 → 搜索 → 试听 → 纠错 → 导出**。预训练模型采用真实的 YAMNet 特征，不用预设的门铃时间戳冒充检测结果。

## 快速开始

如果你下载的是包含模型的 **SoundSeed-v0.1.0 便携包**，解压后双击 `Start-SoundSeed.command`（macOS）或 `Start-SoundSeed.bat`（Windows）；Linux 可运行 `python3 start.py`。需要 Python 3.8+ 和现代桌面浏览器，不需要 Node.js 或重新下载模型。启动器仅在本机提供静态文件，浏览器会自动打开；使用时保持终端窗口开启。缺少 Python 时，可从 [Python 官网](https://www.python.org/downloads/) 安装。

从 GitHub 源码启动：

推荐 **Node.js 24 和 pnpm 11**。使用 pnpm 11 时，Node.js 至少需要 22.13；首次安装依赖和准备模型需要联网。版本兼容性见 [pnpm 安装说明](https://pnpm.io/installation)。

```sh
pnpm install
pnpm setup:model
pnpm dev
```

打开终端显示的本地地址。`setup:model` 会下载 Google 官方 YAMNet 模型并准备本地 WASM 文件；模型约 15 MB。模型和音频都不需要传到 SoundSeed 服务端，应用没有后端。

准备好模型后，可以断开外网并继续运行本地服务。这里的“本地处理”不等于自动安装为离线应用：第一版没有通过 Service Worker 缓存整个站点，不能保证关闭服务后仍可重新打开。

## 用自己的声音试一次

1. 拖入或选择一个本地 WAV 文件，等待特征提取完成。也可以先加载应用内**合成演示**熟悉操作。
2. 在波形上拖动，圈出一个完整的目标声音，试听后添加为正例。每个样例为 0.1–15 秒；推荐从 2–5 个不同背景下的例子开始，减少对某一处噪声的依赖。
3. 查看时间线上的候选片段，点击试听。调整阈值可以扩大或收紧候选范围。
4. 对误报选择“不是目标”，对正确片段进行确认。纠正后结果会更新；误操作可以撤销。
5. 按时间查看结果，或优先检查模型难以判断的片段。导出 CSV 时间戳或 JSON 结果。
6. 保存声音种子，在另一段录音中载入，继续搜索同一个目标。跨录音使用时，仍应试听检查。

候选分数用于排序，**不是经过校准的正确概率**。低分不一定不是目标，高分也需要审核。合成演示用于检查交互和处理流程，不能代表门铃、鸟叫等真实录音的识别效果。

## 第一版做到了什么

| 能力           | v0.1.0                                                        |
| -------------- | ------------------------------------------------------------- |
| 用户自定义目标 | 每次一个声音目标，用少量圈选样例定义                          |
| 本地长录音处理 | 分块读取 WAV，在 Worker 中提取特征，提供进度                  |
| 初始检索       | 根据正例的 YAMNet 特征寻找相似片段                            |
| 交互纠错       | 利用确认的正反例训练轻量分类器，支持撤销                      |
| 审核工作台     | 波形圈选、缩放、候选时间线、试听、阈值与审核优先级            |
| 可移植声音种子 | 保存与载入目标特征，在不同录音间复用                          |
| 结果与评估     | CSV / JSON 导出，导入人工标注，比较召回率、精确率和每小时误报 |

有价值的探索方向是让用户的几次反馈变成可复用的“声音种子”：既能在当天的录音里找声音，也能在另一天继续使用、纠错和评估。少样本声音检测已有研究基础；本项目不声称提出了全新的检测算法，也不声称是世界首创。

## 支持的文件与现实限制

- 支持小端 RIFF WAV：PCM 8 / 16 / 24 / 32 位、IEEE float 32 / 64 位及对应的 extensible 格式。支持 1–32 声道和 8–384 kHz 采样率，分析时混合为单声道并重采样到 16 kHz。
- 试听还取决于浏览器对该 WAV 编码的支持。若能分析但无法播放，请转换为 16-bit PCM WAV。
- 暂不支持 MP3、AAC、FLAC、RF64、实时麦克风、批量文件和多个目标的同时检测。请先将文件转换为普通 WAV。
- 没有硬编码的录音时长上限，但处理时间和可用内存取决于设备、浏览器和文件。1 小时录音的原始 1024 维特征约占 31 MB，实际峰值内存还包括模型、运行时和界面数据。第一版不承诺实时速度或任意长度文件都能完成。
- 模型的分析步长约为 0.48 秒，候选边界是近似定位，不是采样级标注。非常短促、重叠、低信噪比或与背景相似的声音容易漏检。
- 少量反馈可能改善结果，也可能过拟合。设备、距离、房间和日期变化后的效果必须另行验证。

## 怎么验证“找到多少次”

导入完整人工标注后，应用会计算事件级指标：找到的真实事件数、漏检、误报、精确率、召回率及每小时误报。当前录音中已经用作正例或反例的区间会从评估中排除，避免把已教给模型的答案当作测试成绩。

建议用 **A 日录音提供样例、B 日录音纠错、C 日录音最终测试**。同一段录音上的前后变化适合观察交互效果，不能替代跨日期测试。发布实际成绩时，应同时报告录音小时数、目标事件数、样例数、纠错次数、阈值及匹配规则。

第一版尚未公布真实录音上的准确率或每小时误报基准。已完成的真实模型合成回归、浏览器流程与一小时处理路径检查见 [验证记录](docs/validation.md)。完整标注格式、匹配口径和可复现实验步骤见 [评估指南](docs/evaluation.md)；[示例标注](docs/example-ground-truth.json) 是格式示例，不是测得的实验结果。

## 本地与隐私

音频由浏览器的文件接口读取，特征提取、检索与训练在本机运行。没有账号、音频上传接口或服务端推理。YAMNet 权重可以缓存在浏览器的 IndexedDB 中；原始音频不会被应用持久保存。刷新后若要继续处理，请重新打开文件，并按需载入之前导出的声音种子。

导出的结果和声音种子可能包含文件名、时间戳、标注及音频特征。它们不是匿名化证明；分享前请检查文件内容。清除浏览器站点数据可移除模型缓存。

## 开发

```sh
pnpm test
pnpm build
pnpm preview
```

单元测试不下载模型。完整的浏览器推理验收需要先运行 `pnpm setup:model`。部署前也应准备好模型，使 `public` 下的模型和 WASM 文件一起进入静态构建。请勿使用 `file://` 直接打开构建文件，应通过本地或静态 HTTP 服务提供页面。

制作包含模型的便携包：

```sh
pnpm setup:model
pnpm build:release
```

输出位于 `release/SoundSeed-v0.1.0/`，其中包含 `app/`、本地启动器、中文说明及第三方许可。可将整个文件夹压缩后分发。打包过程检查模型、权重、WASM 和许可是否齐全；原始录音不会进入该包。源码仓库不保存这些生成文件。

便携包中的 Python 服务绑定 `127.0.0.1` 自动分配的端口，只提供 `app/` 内的静态文件，关闭目录列表并只允许 GET / HEAD；它不提供音频上传或推理接口。端口可能随重启变化，因此浏览器缓存不保证跨启动复用，但包内始终有本地模型可加载。

实现说明见 [架构文档](docs/architecture.md)，首版边界见 [发布说明](docs/release-notes.md)。

## 依据与许可

- [TensorFlow 官方 YAMNet 迁移学习教程](https://www.tensorflow.org/tutorials/audio/transfer_learning_audio)：冻结预训练特征提取器，训练较小的任务分类器。
- [YAMNet 源码与模型说明](https://github.com/tensorflow/models/tree/master/research/audioset/yamnet)：16 kHz 单声道输入，0.96 秒分析帧、0.48 秒步长及 1024 维特征。
- [DCASE 少样本生物声学事件检测项目](https://github.com/c4dm/dcase-few-shot-bioacoustic)：相关研究与评测背景。SoundSeed 不是该挑战的参赛系统，界面中的评估口径也不是 DCASE 官方评分器。
