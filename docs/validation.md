# v0.1.0 验证记录

本文件记录第一版实际完成的工程检查。它不是跨日期真实录音的准确率报告。

## 真实模型与交互链路

在 Chrome 中运行官方 YAMNet TFJS / WASM。应用内 90 秒合成录音包含 7 个双音门铃及多种干扰音；前 2 个门铃作为正例，阈值固定为 0.70。初始检索给出 9 个候选。将 76.80–77.76 秒的单音提示音标为反例后，剩余 5 个候选，均对应未参与训练的门铃。

公平比较使用同一组正例和反例区间排除，评估时长为 85.94 秒：

| 指标                       | 仅正例 | 加入 1 个反例 |
| -------------------------- | -----: | ------------: |
| 检出的未训练目标事件       |  5 / 5 |         5 / 5 |
| 误报                       |      3 |             0 |
| 精确率                     |  62.5% |          100% |
| 每小时误报（短录音归一化） | 125.67 |             0 |

这是固定合成信号的回归检查；短录音换算出的每小时误报不代表真实部署时的长期水平，也不能据此声称通用识别准确率。复现：`pnpm setup:model && pnpm test`，参见 `tests/search-demo.test.ts`。

浏览器中还验证了候选试听、反例反馈、CSV 导出和声音种子重新导入。CSV 包含 2 个已确认事件和 5 个候选；保存的种子包含 3 个 1024 维特征，重新导入后恢复 5 个候选。模型实际运行，不使用真实标注生成候选。

## 一小时处理路径

一段 1 小时、48 kHz 双声道 PCM 合成静音 WAV（691,200,044 字节）通过分块解码、抗混叠重采样和真实 YAMNet WASM 推理。输出 7,499 帧、约 29.29 MiB 原始特征。本次开发主机的 Node 运行约 36 秒，进程峰值 RSS 约 289 MiB；张量数量未持续增长。

这验证长文件处理与资源释放，不测试声音识别；Node 测量也不是浏览器速度保证，且不包含文件身份校验的额外读取时间。浏览器、设备、样本数量及评估标注会改变性能。

## 待补充的实际证据

首版没有用户的真实跨日期录音，未完成真实环境泛化评测。建议按照 [评估指南](evaluation.md) 使用 A 日提供样例、B 日纠错、C 日冻结测试；同时报告录音总时长、漏检、每小时误报及反馈数量。
