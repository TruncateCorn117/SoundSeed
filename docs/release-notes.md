# SoundSeed v0.1.0

首版交付一个可在本地使用的声音搜索工作台：从 WAV 里圈出几段目标声音，检索候选，试听并纠正误报，导出时间戳。

## 包含的能力

- 本地 WAV 文件读取、降采样波形、圈选与片段试听。
- 在浏览器 Worker 中运行真正的 YAMNet 特征提取；优先使用 WASM。
- 少量正例检索及用户确认正反例驱动的轻量分类器。
- 时间线、候选审核、阈值调整与反馈撤销。
- 声音种子保存 / 载入，以及 CSV / JSON 结果导出。
- 完整人工标注导入，显示事件级精确率、召回率与每小时误报。
- 明确标记的合成演示，以及无需模型下载即可运行的单元测试。
- 可分发的便携包：包含本地模型、WASM、第三方许可和 macOS / Windows 启动器。需要 Python 3.8+ 与浏览器，使用时无需联网下载模型。

## 发布边界

这是可试用的第一版，尚无真实跨日期录音的公开性能基准。它不承诺实时推理、精准到采样点的边界、无限长度录音或通用声音识别准确率。单个目标、WAV、本机浏览器处理是当前范围；多目标、实时输入、其他音频格式与同步协作未包含。

YAMNet 是已有的预训练模型，本项目围绕用户定义目标、可纠正误报、可复用样例和诚实评估构建使用体验。后续改进应优先由真实录音上的失败样例与跨日期测试驱动。

模型权重由 `pnpm setup:model` 从官方来源下载，不随 Git 源码存储；发布静态构建时需要提前准备这些本地资源。

## 便携包

运行 `pnpm setup:model` 后使用 `pnpm build:release`，生成 `release/SoundSeed-v0.1.0/`。压缩整个文件夹即可分发；用户解压后运行对应平台启动器，也可运行 `python3 start.py`。

Python 仅提供静态文件，本机浏览器承担音频处理。服务绑定 `127.0.0.1` 的空闲端口，只允许 GET / HEAD，不列出目录且不能读取 `app/` 之外的文件。首次使用前需要自行安装 Python；这不是无需运行环境的原生桌面安装包。
